🚀 Automation Testing with Selenium Python

A collection of Selenium WebDriver automation scripts developed using Python to demonstrate core web automation concepts and browser interactions. This repository serves as a learning resource for Selenium automation testing and contains practical examples of commonly used automation techniques.


Features

This project includes examples of:

- Selenium WebDriver Commands
- Browser, Application & Navigation Commands
- Finding Web Elements (Locators)
- Wait Commands (Implicit & Explicit)
- Handling JavaScript Alerts
- Working with Frames
- Handling Web Tables
- Mouse Operations
- Keyboard Actions
- Scrolling Web Pages
- Downloading Files (Chrome, Firefox & Edge)
- Capturing Screenshots
- Managing Browser Cookies
- Working with Excel Files
- SQL Database Operations

Tech Stack

- **Language:** Python
- **Automation Framework:** Selenium WebDriver 4.51.0
- **IDE:** PyCharm
- **Package Manager:** pip
- **Environment:** Python Virtual Environment (.venv)
- **Browser:** Google Chrome
- **WebDriver:** ChromeDriver


 Prerequisites

Install the required package:

```bash
pip install selenium
```

For Excel operations:

```bash
pip install openpyxl
```

For SQL examples:

```bash
pip install mysql-connector-python
```

Getting Started

Clone the repository:

```bash
git clone https://github.com/Samyokpoudyal/Automation-Testing.git
```

Navigate to the project:

```bash
cd Automation-Testing
```

Run any script:

```bash
python finding_elements.py
```
